========================================
8. CLAVES TECNICAS
========================================
- Multi-tenant: cada usuario tiene company_id, cada endpoint filtra por empresa
- Roles: SUPER_ADMIN, ADMIN, USER (mayusculas)
- Passwords: hash con passlib bcrypt
- JWT: python-jose, expira 24h
- Clientes: client_type = 'natural' | 'contribuyente' (condicional)
- Productos: image_url = base64 comprimido (canvas 800px, JPEG 70%)
- Workshop: pertenece solo a Etech (company_id=2)
- CORS: allow_origins=["*"] (permite ngrok)
- ngrok header: 'ngrok-skip-browser-warning': 'true' en api.ts

========================================
9. TROUBLESHOOTING
========================================
Vercel no muestra datos:
  1. Verificar ngrok corriendo: Get-Process ngrok
  2. Verificar NEXT_PUBLIC_API_URL en Vercel Settings > Env Vars
  3. Redeploy sin cache en Vercel
  4. Abrir en modo incognito

Backend no inicia:
  1. cd backend && venv\Scripts\activate
  2. uvicorn app.main:app --reload --port 8000 --host 0.0.0.0

Frontend no inicia:
  1. cd frontend && npm run dev -- --hostname 0.0.0.0

Login falla en Vercel:
  1. Verificar que ngrok header esta en api.ts
  2. Verificar token se guarda en localStorage
  3. Verificar NEXT_PUBLIC_API_URL no tiene trailing slash
